# SmartCart Customer Segmentation System

A Machine Learning project that uses **K-Means Clustering** to segment **2,240 customers** into distinct groups based on their purchasing behavior. The project helps businesses improve **personalized marketing**, **customer retention**, and **data-driven decision-making**.

## 🚀 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## ✨ Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- K-Means clustering
- Elbow Method for optimal cluster selection
- Customer segment visualization
- Business insights and recommendations

## 📊 Outcome
Successfully identified customer segments that can be used for targeted marketing campaigns and improved customer engagement.
